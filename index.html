สถาปัตยกรรมระบบ (Architecture)

  • Frontend:
    • Code Editor & Line Highlighter: ช่องพิมพ์โค้ดพร้อมแถบสีไฮไลท์เน้นบรรทัดที่กำลังทำงาน
    • Control Panel: ปุ่มควบคุมการรันโค้ด (Run, Pause, Next Step, Reset) และแถบปรับความเร็ว
    • Variables & Output Inspector: แผงแสดงค่าตัวแปรแบบเรียลไทม์ (กะพริบสีเมื่อค่าเปลี่ยน) และช่องแสดงผลลัพธ์
  • Execution layer: step-by-step interpreter that records state after every line
    • Parser & Compiler: อ่านและแปลงโค้ด Python (รองรับโครงสร้างพื้นฐาน เช่น Variable, Loop, If-Else, List, Dict)
    • Step-by-Step Interpreter: ใช้ JavaScript Generator คอยหยุดและส่งสถานะบรรทัด/ตัวแปรออกมาในทุกๆ ขั้นตอนก่อนไปบรรทัดถัดไป

สื่อการเรียนรู้อินเทอร์แอคทีฟ (Interactive Learning Web Application) เพื่อสอนพื้นฐานวิทยาการคอมพิวเตอร์และดิจิทัลลอจิก ตั้งแต่ระบบเลขฐานสอง ไบนารีบิต ไปจนถึงการทำงานของ CPU ให้ผู้เรียนได้ทดลองเปิด/ปิดสวิตช์ กดปุ่ม และเห็นการเปลี่ยนแปลงของสัญญาณไฟฟ้า LED หรือผลลัพธ์แบบเรียลไทม์

ลำดับขั้นตอนการทำงาน (Execution Steps)

  • เนื้อหาหลักที่ผู้เรียนจะได้ทดลองเล่น (9 บทเรียน)
    1. ระบบตัวเลขฐานสอง (Binary System): สลับสวิตช์ 8 บิต (1 ไบต์) เพื่อดูการแปลงเป็นเลขฐานสิบ
    2. เครื่องบวกเลข 8 บิต (8-bit Adder): จำลองการคำนวณบวกเลขฐานสอง และแสดงสถานะ Overflow
    3. ประตูตรรกะพื้นฐาน (Logic Gates): ทดลองป้อนค่าเข้าเกต AND, OR, NOT, NAND, NOR, XOR, XNOR พร้อมตารางความจริง
    4. การเชื่อมต่อวงจร (NAND Logic): สาธิตการใช้ NAND Gate ซึ่งเป็น Universal Gate นำมาต่อรวมกันเพื่อสร้างวงจรซับซ้อนอย่าง XOR
    5. วงจรถอดรหัส (Decoder): แปลงรหัสไบนารีให้กลายเป็นสัญญาณเลือกตำแหน่ง
    6. วงจรเข้ารหัส (Encoder): แปลงสัญญาณการกดปุ่มให้กลับกลายเป็นรหัสไบนารี
    7. จอแสดงผล 7 ส่วน (7-Segment Display): ถอดรหัส BCD 4 บิต เพื่อเปิดหลอด LED ตัวเลข 0–9
    8. หน่วยคำนวณและตรรกะ (ALU): จำลองส่วนคำนวณของ CPU ตั้งแต่ Half Adder, Full Adder จนถึง 4-bit Adder
    9. หน่วยความจำ (SR Latch Memory): เรียนรู้การเก็บบันทึกข้อมูล (0 หรือ 1) ด้วย Feedback Loop ของประตูตรรกะ
