ระบบเลขฐานสอง (Binary)

รากฐานของทุกอย่างในคอมพิวเตอร์

🤔 ทำไมคอมพิวเตอร์ใช้เลขฐานสอง?

เพราะ CPU ทำงานด้วย ไฟฟ้า — มีแค่สองสถานะ คือ มีไฟ (1) และ ไม่มีไฟ (0) เหมือนสวิตช์ไฟในบ้าน เปิด = 1, ปิด = 0 เมื่อนำมาหลายๆ ตัวมารวมกัน จะแทนตัวเลขใดๆ ก็ได้!

🔢 ค่าของแต่ละบิต — คลิกเพื่อเปิด/ปิด

แต่ละบิตมีค่าเป็น เลขยกกำลัง 2 เรียงจากขวาไปซ้าย

0 0 0 0 0 0 0 0
ผลลัพธ์ทีละหลัก (เรียลไทม์):

💡 เคล็ดลับจำ

บิต 8 ตัว = 1 ไบต์ = แทนตัวเลข 0–255 ได้
2⁷=128, 2⁶=64, 2⁵=32, 2⁴=16, 2³=8, 2²=4, 2¹=2, 2⁰=1
รวมทุกบิตได้ 128+64+32+16+8+4+2+1 = 255

เครื่องบวกเลข 8 บิต (8-bit Adder)

บวกเลขแบบที่ CPU ทำจริงๆ ทีละบิต พร้อม Carry

🔢 8-bit Adder ทำงานอย่างไร?

CPU บวกเลขด้วยการต่อ Full Adder หลายๆ ตัวเป็นสาย — ทุกบิตมี "Carry" ที่ส่งต่อไปบิตถัดไปเหมือนเวลาบวกเลขทศนิยมแล้วทด! ลองกดบิตในแถว A และ B เพื่อดูผล

⚠️ Overflow คืออะไร?

ถ้าผลลัพธ์เกิน 255 (8 บิต) จะเกิด Overflow — carry bit ที่ 9 จะหายไป เหมือนนาฬิกาที่วนกลับ 0 ใหม่ เช่น 200 + 100 = 300 แต่ใน 8 บิตจะได้ 44 (= 300 - 256)

3

Logic Gates

อิฐก้อนแรกของคอมพิวเตอร์ทุกเครื่อง

🎯 Logic Gates คืออะไร?

Logic Gates คือ วงจรอิเล็กทรอนิกส์ขนาดเล็ก ที่รับสัญญาณ 0/1 เข้า และส่งสัญญาณ 0/1 ออก ตาม "กฎ" ของมัน — เหมือนคนทำงานที่มีกฎเฉพาะตัว คลิก Input เพื่อดูผลคำตอบ

4

การต่อประตูตรรกะ

ส่วนที่สำคัญที่สุด — คิดแบบวิศวกรจริงๆ

🔗 แนวคิดหลักในการต่อเกต

ก่อนต่อเกต ให้ถามตัวเองว่า: "Output ควรเป็น 1 เมื่อเงื่อนไขอะไร?"
แล้วเลือกเกตที่ตรงกับเงื่อนไขนั้น เหมือนวางแผนก่อนสร้างบ้าน!

3

4

5

⭐ NAND — ราชาแห่งเกต (Universal Gate)

NAND พิเศษมาก เพราะ สร้างเกตอื่นทุกตัวได้! ในชีวิตจริง chip ส่วนใหญ่ใช้ NAND เท่านั้น

🔧 สร้าง XOR จาก NAND ทีละขั้น

XOR ซับซ้อนกว่า — ต้องใช้ NAND 4 ตัว ดูสัญญาณไหลผ่านแต่ละเกต!

XOR = 1 เมื่อ Input แตกต่างกัน (A≠B). ขณะนี้ A=0, B=0 → Output = 0
5

ดีโคเดอร์ (Decoder)

วงจรที่แปลงรหัสไบนารีเป็น output เดียว

🔍 Decoder คืออะไร — อธิบายง่ายๆ

Decoder คือ วงจรถอดรหัส ที่ช่วยเลือกเปิดไฟหรือส่งข้อมูลไปหาอุปกรณ์เป้าหมายตัวเดียวเท่านั้น โดยดูจากรหัสที่เราป้อนเข้ามา
เปรียบเสมือน สวิตช์เลือกช่องทีวี ที่เมื่อเรากดปุ่มเลือกช่องไหน ทีวีก็จะเปลี่ยนไปฉายช่องนั้นช่องเดียวเท่านั้น!

📐 ทำงานยังไง?

ถ้ามีสวิตช์ป้อนรหัส 2 ตัว (A1, A0) เราจะเลือกช่องปลายทางได้ 4 ช่องทาง:
00 เลือกช่อง Y0, 01 เลือกช่อง Y1, 10 เลือกช่อง Y2, 11 เลือกช่อง Y3
วงจรข้างในใช้เกตพื้นฐานในการตรวจสอบรหัสให้ตรงกับช่องนั้นๆ

1

2
แต่ละ output line ต่อจาก AND gate ที่ตรวจจับ pattern เฉพาะ
3
ทุก output = 0 ยกเว้น output ที่ตรงกับ input เท่านั้น
4
ใช้ใน RAM เพื่อเลือก address, ใน 7-Segment เพื่อเลือก segment

🌍 Decoder ใช้ในชีวิตจริงที่ไหน?

• RAM address decoder — รับ address binary แล้วเลือก memory cell ที่ถูกต้อง
• 7-Segment display driver — รับ BCD 4 บิต แล้วเปิด segment ที่ถูก
• Multiplexer control — เลือก input channel ที่ต้องการส่งออก
• Instruction decoder ใน CPU — รับ opcode แล้วเลือกว่าจะทำ operation ไหน

6

เอนโคเดอร์ (Encoder)

ตรงข้าม Decoder — แปลง input กลับเป็น binary

🔄 Encoder คืออะไร — อธิบายง่ายๆ

Encoder คือ วงจรเข้ารหัส ที่ทำงานสลับกับ Decoder เลยครับ มันจะคอยดูว่าปุ่มไหนหรือสวิตช์ตัวไหนถูกกด แล้วส่งรหัสตัวเลข (0 หรือ 1) ออกมาแทนปุ่มนั้น
เปรียบเสมือน แป้นพิมพ์คอมพิวเตอร์ ที่เมื่อเรากดปุ่มตัวอักษรใดปุ่มหนึ่ง แป้นพิมพ์ก็จะแปลงปุ่มนั้นเป็นรหัสคอมพิวเตอร์ส่งไปประมวลผล!

📐 ทำงานยังไง?

ถ้ามีสวิตช์ให้เราเลือกกด 4 สวิตช์ (I0 ถึง I3) เมื่อเรากดตัวใดตัวหนึ่ง วงจรจะแปลงเป็นรหัส 2 ตัว (A1, A0) ทันที:
กดสวิตช์ I0 ได้รหัส 00, กด I1 ได้รหัส 01, กด I2 ได้รหัส 10, กด I3 ได้รหัส 11

🌍 Encoder ใช้ที่ไหนในชีวิตจริง?

• แป้นพิมพ์ (Keyboard) — กดปุ่มหนึ่ง → ส่ง binary keycode ออกไป
• Priority Encoder — ถ้ามีหลาย input active พร้อมกัน เลือก input ที่ priority สูงสุด
• ADC (Analog to Digital Converter) — แปลงสัญญาณแอนะล็อกเป็น binary ดิจิทัล
• Mouse/Touchpad — แปลงตำแหน่ง XY เป็น binary coordinate

เส้น 7 เส้นที่แสดงเลข 0–9

💡 7-Segment ทำงานอย่างไร?

จอ 7-segment มี segment 7 ส่วน: a, b, c, d, e, f, g แต่ละส่วนคือ LED หนึ่งดวง

8

ALU — Arithmetic Logic Unit

หัวใจของ CPU — บวก ลบ AND OR ทุกอย่างอยู่ที่นี่

🧠 ALU คืออะไร?

ALU คือวงจรที่ทำ การคำนวณทั้งหมด ในคอมพิวเตอร์ ทั้งคณิตศาสตร์ (บวก ลบ) และตรรกศาสตร์ (AND OR XOR)
ทุกครั้งที่ CPU รัน instruction เช่น ADD R1, R2 — ALU คือตัวที่ทำการบวกนั้น!

⚙️ Half Adder — บวก 1 บิต

Half Adder คือ building block พื้นฐานที่สุด รับ 2 input bits (A, B) → ให้ Sum (XOR) และ Carry (AND)

Sum = A XOR B  |  Carry = A AND B
ตัวอย่าง: 1 + 1 = Sum=0, Carry=1 (เหมือนทดเลข 1+1=10 ในฐานสอง)

🌍 ALU ทำอะไรได้บ้างใน CPU จริง?

• คณิตศาสตร์: ADD, SUB, MUL, DIV
• ตรรกศาสตร์: AND, OR, XOR, NOT
• เปรียบเทียบ: >, <, == (ผ่าน SUB แล้วดู flag)
• Shift: เลื่อนบิตซ้าย/ขวา (= คูณ/หารด้วย 2)
Intel Core i9 มี ALU หลายร้อยตัวทำงานพร้อมกัน (superscalar execution)!

หน่วยความจำ (Memory)

วิธีที่วงจรจำค่าได้

🧠 วงจรจะ "จำ" ได้อย่างไร?

วงจรดิจิทัลปกติ output ขึ้นอยู่กับ input ณ เวลานั้น แต่ถ้าเราต้องการ "จำ" ค่าไว้ ต้องใช้ feedback loop — ส่ง output กลับมาเป็น input ของตัวเอง!

🔄 SR Latch — วงจรจำพื้นฐาน

SR Latch ใช้ NOR gate 2 ตัวต่อแบบ cross-coupled เมื่อ SET จะจำ 1, เมื่อ RESET จะจำ 0 แม้ตัด input แล้ว!
